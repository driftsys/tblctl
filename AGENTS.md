# AGENTS.md

Instructions for AI coding agents working in this repository.

## Project

`tblctl` — converts and checks tables for Markdown docs. Sibling of
[`diagctl`](https://github.com/driftsys/diagctl) and
[`pixctl`](https://github.com/driftsys/pixctl). Scope: issue
[#1](https://github.com/driftsys/tblctl/issues/1).

Rust 2021, `clap` derive. Exit contract: `0` clean · `1` ≥1 check failed · `2`
operational error (`src/output.rs` `finish` computes the code).

## Build commands

```bash
just            # list recipes
just fmt        # prim + cargo fmt, in place
just build      # full local gate (toolchain, prim, fmt, compile, test, clippy, shellcheck, install test)
just verify     # commit-message lint + full gate — run before opening a PR
just release    # git-std bump (changelog + tag) on a clean, CI-green main
```

CI (`.github/workflows/ci.yml`) runs only `just` recipes. Releases are built by
cargo-dist (`release.yml`) on a `v*` tag.

## Workflow

- Conventional Commits, enforced by the `commit-msg` hook (`git std lint`) with
  the scopes in `.git-std.toml`.
- `CHANGELOG.md` is generated by git-std. Never edit it by hand.
- Feature work on short-lived branches, merged via PR.
